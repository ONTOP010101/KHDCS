## 九、动态字号规则

### 出厂货号（factoryCode）

| 字符数 | 字号 | 换行 |
|--------|------|------|
| ≤ 12 字 | **13px** | 不换行 |
| 13~15 字 | **10px** | 不换行 |
| 16~23 字 | **8px** | 不换行 |
| ≥ 24 字 | **6px** | 最多2行换行 |

- 换行实现：`display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; word-break:break-all`
- 换行时父行 `align-items:flex-start`，`max-height` = 字号 × 2 × 1.1
- 非换行时使用 `<span class="lb-pack">`，行 `min-height:13px` 锁定行高

### 样品名称（sampleName）

| 字符数 | 字号 | 换行 |
|--------|------|------|
| ≤ 20 字 | **12px** | 最多2行 |
| 21~39 字 | **10px** | 最多2行 |
| 40~43 字 | **7px** | 最多2行 |
| ≥ 44 字 | **6px** | 最多2行 |

- 换行由 `.lb-name` CSS类统一控制：`display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; word-break:break-all`
- `min-height:12px` 锁定行高，防止字号变小导致行距塌缩

## 十、四等分条码标签规格（25mm × 25mm）

> 标签尺寸：**25mm × 25mm** | 背景色：**#fff（白色）** | 字体：**SimSun（宋体）**

### 标签排版布局

```
┌──────────────────────┐
│     YX0175596        │  ← 出厂货号, 顶部居中, 动态字号
│                      │
│ 吊卡    ┌─────┐  1991 │  ← 左:中文包装竖排(8px) | 中:QR(46×46) | 右:公司编号竖排(8px)
│        │ QR码 │  010  │     writing-mode:vertical-rl        writing-mode:vertical-lr
│        └─────┘       │
│                      │
│      290001          │  ← 摊位号, 底部居中, 9px
└──────────────────────┘
```

### 字号与粗细

| 元素 | 字号 | 排版方式 |
|------|------|----------|
| 出厂货号 | **动态四档**（见下） | 横排, 顶部居中, absolute定位 |
| 中文包装 | **8px** | 竖排, QR左侧, `writing-mode: vertical-rl`, 最多5行 |
| 二维码 | **46×46px** | 居中, `transform: translate(-50%,-50%)` |
| 公司编号 | **8px** | 竖排, QR右侧, `writing-mode: vertical-lr` |
| 摊位号 | **9px** | 横排, 底部居中, absolute定位 |

### 出厂货号动态字号

| 字符数 | 字号 |
|--------|------|
| ≤ 8 字 | **9px** |
| 9~12 字 | **8px** |
| 13~16 字 | **7px** |
| ≥ 17 字 | **6px** |

### 二维码

| 参数 | 值 |
|------|-----|
| CSS 尺寸 | **46×46px** |
| 定位方式 | position: absolute, 居中 (top:50%, left:50%, translate -50%) |
| 生成参数 | `QRCode.toDataURL(code, { width: 120, margin: 0, scale: 4 })` |

### 打印设置

| 参数 | 值 |
|------|-----|
| 打印页尺寸 | `@page { size: 25mm 25mm; margin: 0 }` |
| 每标签一页 | page-break-after: always（最后一张: auto） |

### 数据字段映射

| 标签位置 | 数据库字段 |
|----------|------------|
| 出厂货号（顶部） | `factoryCode` 或 `packageCode` |
| 二维码内容 | `sampleCode` |
| 中文包装（左侧竖排） | `packagingCn` |
| 公司编号（右侧竖排） | `sampleCode` |
| 摊位号（底部） | `boothNo` |
