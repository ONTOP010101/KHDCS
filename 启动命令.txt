============================
  照片管理系统 - 启动命令
============================

【1. 启动后端 (Spring Boot)】
  cd d:\客户端测试\backend
  mvn spring-boot:run
  （运行在 http://localhost:8080）

  如果 mvn 找不到，用完整路径：
  C:\Users\wd439\apache-maven-3.9.6\bin\mvn spring-boot:run

  后端端口：8080
  配置文件：d:\客户端测试\backend\src\main\resources\application.yml


【2. 启动前端 (Vite Dev Server)】
  cd d:\客户端测试\frontend
  npm run dev
  （运行在 http://localhost:3000 或 http://localhost:3002）

  前端端口：3000（如被占用会顺延到3001、3002等）
  代理配置：d:\客户端测试\frontend\vite.config.js


【3. 启动 Electron 桌面端】
  cd d:\客户端测试\frontend
  npm run dev:electron


【依赖说明】
  - Java 17+
  - Maven 3.9（C:\Users\wd439\apache-maven-3.9.6）
  - Node.js + npm
  - MySQL 8.0
  - FFmpeg（需添加到系统 PATH，用于视频 H.264 压缩）


【存储路径】
  - 图片原图：d:\客户端测试\photo-management\images
  - 缩略图：  d:\客户端测试\photo-management\thumbnails
  - 视频文件：d:\客户端测试\photo-management\videos
  - 上传临时：d:\客户端测试\photo-management\uploads
